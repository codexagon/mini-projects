# mini projects

A collection of fun, small projects.

Many of these projects are inspired (more like taken from) [Daniel Hirsch](https://www.youtube.com/@HirschDaniel).

# dependencies

`raylib` is needed to run some of these projects, so make sure it is installed.

# build instructions

Use the `Makefile` in each project folder to build the project.

Or you could compile them yourself, it's pretty simple anyway.

# project list

- Analog clock
- Double pendulum simulation
- Function plotter
- Cellular automata simulations (conway, wireworld)
- File watcher
- Puzzle timer
